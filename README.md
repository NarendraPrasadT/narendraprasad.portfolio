# Narendra Prasad — Starburst Creative Portfolio

A complete static portfolio website with the editorial black/white + lime starburst aesthetic, responsive layout, scroll reveals, subtle 3D tilt and cursor interactions.

## Run locally

1. Extract the ZIP.
2. Open `index.html` in Chrome or Edge.

**No npm, package.json, or build required.** You can also use VS Code's Live Server extension.

## Host for free

Upload the folder containing `index.html`, `style.css`, `script.js`, and `assets/` to Netlify Drop, or push it to a GitHub repository and deploy with Netlify/Vercel as a static site (no build command, publish directory `.`).

## Customize

- `index.html`: text, links, project descriptions
- `style.css`: design, colors, typography
- `script.js`: interactive behavior
- `assets/profile.png`: original profile photo
- `assets/NarendraPrasad-Resume.pdf`: resume download

Note: the listed skills and project details are based on the supplied resume. Additional work and metrics have not been invented.
